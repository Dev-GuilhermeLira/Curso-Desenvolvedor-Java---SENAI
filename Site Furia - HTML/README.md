# ☠️ FURIA CS2 --- Versão HTML

## Sobre o projeto

O **FURIA CS2** é um site informativo desenvolvido em HTML como
atividade acadêmica do curso de Java do SENAI. O projeto apresenta
conteúdos relacionados à equipe FURIA de Counter-Strike 2, reunindo
informações sobre a composição do time, estatísticas, títulos, partidas
e próximos confrontos.

Esta versão concentra a estrutura e a apresentação visual em um único
arquivo HTML, utilizando CSS incorporado na tag `<style>` e atributos
`style` diretamente nos elementos.

## Funcionalidades e conteúdo

-   **Apresentação da equipe:** título e imagem principal da FURIA.
-   **Composição do time:** tabela com nomes, apelidos, funções e
    nacionalidades dos integrantes.
-   **Estatísticas:** link externo para a página da FURIA no portal
    HLTV.
-   **Títulos:** lista de campeonatos e colocações apresentadas no site.
-   **Melhores momentos:** texto sobre uma partida e link externo para
    um vídeo no YouTube.
-   **Próximos confrontos:** tabela com campeonato, confronto, fase e
    horário/status.
-   **Identidade visual:** favicon, cores, fontes e alinhamentos
    definidos no próprio HTML.

## Tecnologias utilizadas

-   **HTML5:** estruturação e organização do conteúdo.
-   **CSS3:** estilização incorporada ao documento HTML, por meio da tag
    `<style>` e de estilos inline.

Não há arquivos JavaScript, backend ou banco de dados nesta versão.

## Como executar

1.  Baixe ou clone o repositório.
2.  Mantenha o arquivo `site.html` e as imagens na estrutura de pastas
    apresentada.
3.  Abra o arquivo `site.html` em um navegador de internet.

Não é necessário instalar dependências ou configurar um servidor para
visualizar a página localmente.

## Recursos externos

O site utiliza recursos hospedados em serviços externos:

-   **HLTV:** link para estatísticas da equipe ---
    https://www.hltv.org/team/8297/furia
-   **YouTube:** link para assistir aos melhores momentos da partida.
-   **FlagCDN:** imagens das bandeiras utilizadas nas tabelas.

A disponibilidade desses recursos depende dos respectivos serviços e de
conexão com a internet.

## Observações

-   As informações sobre elenco, títulos e confrontos estão inseridas
    diretamente no HTML; não são atualizadas automaticamente.
-   O projeto é uma página estática e não possui integração com APIs.
-   As imagens locais precisam permanecer junto ao arquivo HTML para que
    os caminhos relativos continuem funcionando.

## Objetivo acadêmico

O projeto tem como finalidade praticar a criação de páginas web com HTML
e CSS, trabalhando conceitos de estruturação de conteúdo, tabelas,
listas, imagens, links externos e estilização.
