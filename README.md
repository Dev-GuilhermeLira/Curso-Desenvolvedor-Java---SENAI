# 💻 Portfólio de Projetos

## Sobre

Este repositório reúne projetos desenvolvidos com finalidade acadêmica e prática, aplicando conceitos de lógica de programação e desenvolvimento web. Cada projeto possui uma proposta própria e utiliza tecnologias adequadas ao seu objetivo.

A documentação apresenta uma visão geral dos trabalhos, suas principais funcionalidades e as tecnologias utilizadas.

## 📚 Projetos

### 1. Conversor de Moedas

**Linguagem:** Portugol

Programa de conversão de valores em Reais (R$) para moedas internacionais, desenvolvido para praticar lógica de programação, estruturas condicionais e operações matemáticas.

**Principais funcionalidades:**
- Conversão de Reais para Dólar, Euro e Bitcoin.
- Aplicação de uma taxa de 10% antes da conversão.
- Exibição do valor convertido e da taxa aplicada.
- Menu de opções para selecionar a moeda ou encerrar o programa.

**Observação:** as cotações são definidas diretamente no código e não são atualizadas automaticamente.

### 2. FURIA CS2 — Site informativo

**Tecnologias:** HTML5 e CSS3

Site estático com informações sobre a equipe FURIA de Counter-Strike 2.

O projeto foi desenvolvido em duas versões:

- **Versão HTML:** estrutura e conteúdo em um arquivo HTML, com CSS incorporado por meio da tag `<style>` e de estilos inline.
- **Versão HTML + CSS:** estrutura HTML separada da apresentação visual, que fica concentrada em uma folha de estilos externa (`style.css`).

**Conteúdo apresentado:**
- Apresentação da equipe.
- Composição do time.
- Estatísticas com acesso à página da equipe na HLTV.
- Títulos e resultados apresentados.
- Área de melhores momentos com referência a vídeo.
- Tabela de próximos confrontos.

**Observação:** os dados são inseridos diretamente na página. O site não possui integração com API ou atualização automática de resultados.

### 3. Beauty Studio Kátia Souza

**Tecnologias:** HTML5, CSS3 e JavaScript

Site institucional desenvolvido como projeto acadêmico para um estúdio de beleza especializado em cuidados com as unhas. Seu objetivo é apresentar o negócio, divulgar os serviços, exibir trabalhos realizados e facilitar o contato e as solicitações de agendamento pelo WhatsApp.

**Identidade visual:**

O projeto utiliza uma identidade minimalista chamada *Gray Minimal*, com tons de branco, cinza e grafite. A composição utiliza Playfair Display nos títulos e Montserrat nos textos, menus e botões, priorizando uma navegação limpa e consistente.

**Páginas:**
- **Início:** apresentação do estúdio e destaques do conteúdo.
- **Serviços:** exibição dos serviços oferecidos.
- **Agendamento:** formulário para solicitar um horário.
- **Sobre:** apresentação da profissional e de sua experiência.
- **Galeria:** fotografias dos trabalhos realizados.
- **Contato:** informações de contato, redes sociais e horários de funcionamento.

**Serviços apresentados:**
- Manicure tradicional.
- Esmaltação em gel.
- Alongamento de unhas.
- Nail art.

**Formulário de agendamento:**

O visitante pode informar nome completo, telefone ou WhatsApp, serviço desejado, data preferencial, horário e observações adicionais. O JavaScript organiza os dados em uma mensagem e direciona o visitante ao WhatsApp do estúdio. O campo de telefone possui formatação automática para o padrão brasileiro `(00) 0 0000-0000`.

**Horário de funcionamento informado no site:**
- Segunda a sexta-feira: 07h às 18h.
- Sábado: 14h às 17h.
- Domingo: fechado.

**Observação:** o formulário não realiza reservas automaticamente, não consulta disponibilidade em tempo real e não armazena dados em banco de dados. O agendamento depende do envio da mensagem pelo cliente e da confirmação do estúdio. A integração com a plataforma Tua Agenda e outras funções de gerenciamento aparecem como possibilidades de melhorias futuras, não como recursos já implementados.

## ▶️ Como executar

Cada projeto possui sua própria forma de execução:

- **Conversor de Moedas:** abra o arquivo `.por` em um ambiente compatível com Portugol e execute o programa.
- **FURIA CS2:** abra o arquivo HTML correspondente em um navegador. Na versão HTML + CSS, mantenha o arquivo `style.css` e as imagens nos caminhos esperados pelo HTML.
- **Beauty Studio Kátia Souza:** abra o arquivo `index.html` em um navegador, mantendo as pastas `css`, `js` e `Imagens` conforme os caminhos utilizados pelo projeto. Também é possível utilizar a extensão Live Server no Visual Studio Code durante o desenvolvimento.

Consulte a documentação específica de cada projeto para obter detalhes adicionais de estrutura e execução.

## 🎯 Objetivo do portfólio

Reunir projetos que demonstram a aplicação prática de conhecimentos em lógica de programação e desenvolvimento web, registrando a evolução do aprendizado por meio de exercícios e páginas com diferentes objetivos.
